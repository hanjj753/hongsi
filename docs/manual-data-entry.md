# Supabase 초기 데이터 입력 순서

운영 사이트 `hongsi-eta.vercel.app`은 현재 Supabase 프로젝트 `hongsi-dev`를 데이터베이스로 사용한다. 프로젝트 이름은 개발 단계에서 붙인 것이며, 운영 사이트의 입력과 수정은 이 DB에 실제로 저장된다.

분기·수업·차시·학생·성적은 이제 Supabase Table Editor를 열지 않고 앱에서 입력한다. `id`, 관계 ID, 숫자 요일 배열을 직접 다룰 필요가 없다.

## 1. 장소

1. 개발 앱에서 **수업 탭 → 위치 보기**를 누른다.
2. 관리자 또는 매니저 계정으로 `+`를 눌러 장소명, 위도·경도, 비고를 입력한다.
3. 위도와 경도는 `37.123, 127.123`처럼 함께 입력한다.

현재 `locations`에 이미 입력한 행은 그대로 사용한다. 수업이 참조하는 장소 삭제는 기록 보호를 위해 아직 앱에서 지원하지 않는다.

## 2. 분기와 수업

1. **수업 탭 → 분기/수업 관리**를 누른다.
2. **분기 추가**에서 `2026-2F` 같은 분기 이름을 입력한다.
3. 분기를 선택하고 **수업 추가**를 누른다.
4. 학교, 과목, 요일, 장소, 시작·종료 시간, 기본 시급을 입력한다. 학교와 과목 중 하나 이상은 필요하고 시작·종료 시간은 함께 입력한다.
5. 기존 수업의 **수정**으로 내용을 바꾼다.

분기 이름을 수정하면 소속 수업도 새 이름을 사용한다. 수업이나 분기의 **삭제**는 학생·차시·성적 기록을 실제로 지우지 않고 목록에서 숨기는 보관 방식이다. 삭제한 수업은 같은 분기의 관리 목록에서 복구할 수 있고, 삭제한 분기는 같은 이름으로 다시 추가하면 활성화된다.

## 3. 차시 일정

1. 수업 목록에서 수업을 선택한다.
2. 수업 일정 제목 옆의 **일정 추가** 또는 마지막 차시 옆의 **차시 추가**를 누른다.
3. 날짜와 차시 번호를 입력한다. 반복 등록에서는 기준일, 요일, 횟수를 선택해 최대 60개를 한 번에 만든다.
4. 같은 수업 안에서 차시 번호는 중복할 수 없다.

예정 근무자는 현재 활성 조교 목록에서 한 명 이상 또는 없음으로 선택할 수 있다. 처음 열면 수업의 기본 담당 조교가 선택되어 있고, 이 선택은 새로 만드는 차시에 저장된다. 조교 등록·수정은 조교 탭, 수업 기본 담당자 관리는 분기/수업 관리에서 한다.

## 4. 학생

1. 수업 상세의 **수강 학생** 영역에서 학생 ID·이름·학생 전화번호·학부모 전화번호·이메일·기본 수신자·수강 시작일을 입력한다.
2. 학생 ID는 비워 두면 자동 생성된다. 직접 입력한 같은 학생 ID는 모든 수업에서 같은 학생을 뜻한다.
3. 전화번호는 한국 휴대전화 형식이어야 하며 저장할 때 숫자로 정규화된다.
4. 관리자·매니저가 새 학생을 저장하면 학생 정보와 수강 관계가 한 트랜잭션으로 함께 처리된다.
5. 학생 ID는 분기가 바뀌어도 유지된다. 수강 상태는 `수강 중`, `전반`, `퇴원`으로 표시한다.
6. 같은 분기에서 반을 옮기면 **학생 전반**을 누르고 학생·옮길 수업·전반일을 고른다. 전반일 전 기록은 이전 반에 남고, 전반일부터 새 반에 나타난다.
7. 수강을 끝내거나 다시 시작할 때 학생 행의 **퇴원/수강 재개**를 사용한다.

## 5. 출석·숙제·시험

1. 차시를 선택하고 **차시 항목 구성**에서 숙제와 시험을 추가한다.
2. 항목의 **수정**으로 이름이나 시험 만점을 고칠 수 있다. 새 만점보다 높은 기존 점수가 있으면 학생 점수를 먼저 수정해야 한다.
3. 항목의 **삭제**는 확인 후 해당 항목의 모든 학생 결과도 함께 영구 삭제한다.
4. 출석은 `출석`, `영상`, `보강`, `결석` 중 하나다. 보강이면 날짜와 필요할 때 시각 또는 메모를 함께 입력한다.
5. 숙제 결과는 `A`, `B`, `C`, `미제출`, 시험은 점수 또는 `결시`를 입력한다. 점수와 만점은 소수점 둘째 자리까지 허용한다.
6. 학생은 이름 가나다순으로 표시된다. 여러 학생을 입력한 뒤 **표 전체 저장**을 한 번 누른다.
7. 항목 통계에서 숙제 등급별 인원과 시험의 평균·최고·최저·결시 인원을 확인한다. 표의 값을 바꾸면 저장 전에도 통계가 갱신된다.
8. 다른 반 학생이 이 차시에 보강 오면 **다른 반 보강 학생**을 누른다. 학생과 원래 반 A를 선택한 뒤, A에서 보강으로 처리할 차시를 함께 선택한다. 실제 보강 반 B의 차시가 A 차시보다 먼저여도 뒤여도 관계없다.
9. A에는 `다른 반 보강 → B n차시`가 자동으로 남고, B에는 `보강 참여 · A · n차시`로 표시된다. B의 표에서 출석·숙제·시험을 입력한다. B에서 보강 학생을 제거하면 B의 기록과 A의 연결 상태가 함께 정리된다.
10. 수업 탭의 **전체 학생 기록**에서 학생을 검색하면 A와 B 양쪽 차시의 연결 관계와 B에서 입력한 출석·숙제·시험을 함께 확인할 수 있다.

`messages`, `message_deliveries`는 문자 기능을 연결한 뒤 입력한다. `work_logs`는 조교 탭과 수업 상세의 출퇴근 기능을 사용해 기록한다.
